# 📥 Installation

## Step 1: Download the Application

Download the latest **Release.zip** from the GitHub Releases section.

## Step 2: Extract the Files

1. Right-click on `Release.zip`
2. Select **Extract All**
3. Choose your preferred location
4. Complete extraction

## Step 3: Launch the Application

Open the extracted folder and run:

```bash
murtuza_khalid_vu_ai_tutor.exe
```

---

# 🤖 Download AI Model

Download the LFM AI Model from:

https://drive.google.com/drive/folders/1aplRskvdZQGMogVcCz-xcSZXCgBACUL4?usp=sharing

Wait for the download to complete before proceeding.

---

# ⚙️ Configure the AI Model

1. Launch **Murtuza Khalid Virtual University AI Tutor**
2. Open **Settings**
3. Click **Select Model**
4. Navigate to the downloaded LFM model
5. Select the model file
6. Click **Save Settings**

# 🛠 Troubleshooting

## Model Not Loading

* Verify the model downloaded successfully.
* Ensure the correct model file is selected.
* Restart the application.

## Application Not Starting

* Run the application as Administrator.
* Verify all extracted files remain together.
* Check Windows Security or Antivirus settings.

## Slow Responses

* Close unnecessary applications.
* Ensure sufficient RAM is available.
* Use a smaller AI model if needed.
